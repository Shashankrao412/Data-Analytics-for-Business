# 📊 Finance KPI Dashboard – Power BI

A Power BI dashboard project that analyzes an organization's financial performance by comparing **Budget vs Actual Expenses**. The dashboard helps identify overspending, monitor budget utilization, and provide data-driven insights for better financial planning.

## 🚀 Project Overview

This project was developed as part of the **Data Analytics for Business** course. It uses interactive Power BI visualizations to track financial KPIs across departments, regions, categories, and payment methods.

## ✨ Features

- 📌 KPI Cards (Total Budget, Total Actual, Budget Variance)
- 📈 Budget Utilization & Overspending Analysis
- 🏢 Department-wise Budget vs Actual Comparison
- 📅 Monthly Expense Trend Analysis
- 🌍 Region-wise Financial Performance
- 💰 Category-wise Expense Breakdown
- 💳 Payment Method Distribution
- 🎛 Interactive Filters (Year, Department, Region, Category)
- 📋 Transaction-Level Details
