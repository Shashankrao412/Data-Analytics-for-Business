# 🛒 Walmart Sales Dashboard | Power BI

## 📌 Project Overview
This project presents an interactive Walmart Sales Dashboard developed using Microsoft Power BI. The dashboard helps analyze sales performance across different stores, time periods, holidays, and external factors. It enables users to gain valuable business insights through dynamic visualizations and KPIs.

---

## 🎯 Objectives
- Analyze overall sales performance.
- Compare sales across Walmart stores.
- Identify weekly sales trends.
- Analyze holiday vs non-holiday sales.
- Study the impact of fuel price, CPI, unemployment, and temperature on sales.
- Create an interactive dashboard for business decision-making.

---

## 📂 Dataset
- **Dataset:** Walmart Sales Dataset
- **Source:** Kaggle
- **Format:** CSV
- **Records:** Weekly sales data of multiple Walmart stores.

### Dataset Columns
- Store
- Date
- Weekly_Sales
- Holiday_Flag
- Temperature
- Fuel_Price
- CPI
- Unemployment

## 📊 Dashboard Features

## 🚀 Steps to Build the Dashboard

1. Download the Walmart Sales Dataset.
2. Import the dataset into Power BI.
3. Clean and transform data using Power Query.
4. Create relationships (if required).
5. Create DAX measures:
   - Total Sales
   - Average Sales
   - Maximum Sales
6. Design KPI Cards.
7. Add charts and slicers.
8. Format the dashboard.
9. Publish the report to Power BI Service (optional).
